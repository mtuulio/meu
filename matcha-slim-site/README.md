Um site moderno e responsivo para promover o produto emagrecedor Matcha Slim, disponível em português e francês.

## 📁 Estrutura do Projeto

```

│   ├── index.html          # Página principal
```

## 🚀 Como Usar

### Abrir o Site
1. Navegue até a pasta desejada (`pt/` ou `fr/`)
2. Abra o arquivo `index.html` em um navegador
3. Ou sirva através de um servidor web local

### Servidor Local (Opcional)
```bash
# Python 3
python -m http.server 8000

# Node.js (se tiver http-server instalado)
npx http-server

# PHP
php -S localhost:8000
```

## 🔧 Personalização

### Modificar Cores
Edite as variáveis CSS no arquivo `style.css`:
```css
/* Cores principais */
--primary-green: #4CAF50;
--dark-green: #2E7D32;
--accent-orange: #FF6B35;
```

### Adicionar Conteúdo
- Edite o arquivo `index.html` para modificar textos
- Adicione novas seções seguindo a estrutura existente
- Modifique os depoimentos na seção de testimonials

### Funcionalidades JS
- Edite `script.js` para adicionar novas funcionalidades
- Modifique animações e efeitos visuais
- Adicione tracking de conversão se necessário
