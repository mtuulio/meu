# 📁 Pasta HTML - Projeto de Tradução

## Conteúdo da Pasta

### 🌐 Arquivos HTML Principais:

1. **`index_visualizacao.html`** ⭐
   - Página principal com índice de todos os arquivos
   - Abra este arquivo primeiro para navegar pelos outros
   - Design moderno e responsivo

2. **`exemplo_site_espanhol.html`**
   - Site completo em espanhol (exemplo)
   - Demonstra o tipo de site que pode ser traduzido

3. **`exemplo_site_portugues.html`**
   - Versão traduzida do site acima
   - Mostra o resultado final da tradução

### 📚 Documentação:

- **`INSTRUCOES_TRADUCAO.md`** - Como enviar seu site para tradução
- **`RESUMO_PROJETO.md`** - Visão geral do projeto
- **`COMO_VISUALIZAR.md`** - Instruções de visualização

### 🎨 Arquivos de Estilo:

- **`style.css`** - Estilos do sistema de estacionamento
- **`script.js`** - JavaScript do sistema principal
- **`script_mensalista.js`** - JavaScript específico

## 🚀 Como Usar:

### Para visualizar os exemplos:

1. **Extraia o arquivo ZIP** em uma pasta no seu computador
2. **Abra `index_visualizacao.html`** no navegador
3. Use os links para navegar entre os arquivos

### Estrutura sugerida:
```
📂 MeuSite/
├── 📄 index_visualizacao.html (ABRA ESTE PRIMEIRO!)
├── 📄 exemplo_site_espanhol.html
├── 📄 exemplo_site_portugues.html
├── 📄 INSTRUCOES_TRADUCAO.md
├── 📄 RESUMO_PROJETO.md
├── 📄 COMO_VISUALIZAR.md
├── 📄 style.css

```
