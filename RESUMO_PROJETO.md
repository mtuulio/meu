# E-book Ilustrado: Jesus e a Mulher Samaritana

## ✅ Projeto Concluído com Sucesso!

Criei um e-book ilustrado completo no estilo história em quadrinhos baseado na passagem bíblica de João capítulo 4, onde Jesus conversa com uma mulher samaritana. Todo o conteúdo está em português brasileiro conforme solicitado.

## 🚀 Como Utilizar

### Método Simples:
1. Navegue até a pasta `ebook-joao4`
2. Clique duas vezes em `index.html`
3. O e-book abrirá no navegador
4. Clique em "Começar a Leitura"

### Método Servidor (Recomendado):
```bash
cd ebook-joao4
python -m http.server 8000
# Acesse: http://localhost:8000
```
