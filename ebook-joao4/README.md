# Jesus e a Mulher Samaritana - E-book Ilustrado

Um e-book interativo no estilo história em quadrinhos baseado na passagem bíblica de João capítulo 4, onde Jesus conversa com uma mulher samaritana junto ao poço de Jacó.

## 📖 Sobre o Projeto

Este e-book apresenta a narrativa de João 4:1-42 de forma visual e interativa, dividida em capítulos temáticos que seguem a sequência da conversa entre Jesus e a mulher samaritana. Todo o conteúdo está em português brasileiro.

### 🎯 Características

- **10 capítulos** divididos em páginas temáticas
- **Design responsivo** que funciona em desktop, tablet e mobile
- **Navegação intuitiva** com botões, teclado e gestos touch
- **Estilo história em quadrinhos** com balões de fala e narração
- **Animações suaves** entre páginas e elementos
- **Progresso salvo automaticamente** no navegador
- **Modo tela cheia** disponível
- **Controle de zoom** (Ctrl + scroll do mouse)

## 📱 Como Visualizar

### Opção 1: Abrir diretamente no navegador
1. Abra o arquivo `index.html` em qualquer navegador moderno
2. O e-book funcionará completamente offline

### Opção 2: Servidor local (recomendado)
```bash
# Navegue até a pasta do projeto
cd ebook-joao4

# Usando Python 3
python -m http.server 8000

# Usando Python 2
python -m SimpleHTTPServer 8000

# Usando Node.js (se tiver instalado)
npx serve .
```

Depois acesse: `http://localhost:8000`

## 🎮 Controles de Navegação

### Desktop
- **Setas ← →**: Navegar entre páginas
- **Espaço**: Próxima página
- **Home**: Ir para a capa
- **End**: Ir para a página final
- **Esc**: Voltar à capa
- **Ctrl + Scroll**: Zoom in/out

### Mobile/Tablet
- **Swipe horizontal**: Navegar entre páginas
- **Toques nos botões**: Navegação tradicional

### Botões na Interface
- **← Anterior**: Página anterior
- **Próximo →**: Próxima página
- **Começar a Leitura**: Da capa para primeira página
- **Ler Novamente**: Da página final para a capa

## 📋 Estrutura do E-book

1. **Capa** - Apresentação do título e referência bíblica
2. **Capítulo 1: A Jornada** - Jesus deixa a Judéia
3. **Capítulo 2: O Poço de Jacó** - Chegada ao poço
4. **Capítulo 3: O Encontro** - Jesus pede água
5. **Capítulo 4: A Água Viva** - Jesus fala sobre água viva
6. **Capítulo 5: A Fonte da Vida** - A água que sacia para sempre
7. **Capítulo 6: A Verdade Revelada** - Jesus revela o passado da mulher
8. **Capítulo 7: A Verdadeira Adoração** - Discussão sobre adoração
9. **Capítulo 8: O Messias Revelado** - Jesus se revela como o Cristo
10. **Capítulo 9: O Testemunho** - A mulher testemunha na cidade
11. **Capítulo 10: O Salvador do Mundo** - A fé dos samaritanos
12. **Página Final** - Conclusão e reflexão

## 📚 Base Bíblica

O e-book é baseado integralmente no texto de **João 4:1-42** da Bíblia Sagrada, mantendo fidelidade ao texto original enquanto apresenta a narrativa de forma visual e envolvente.

### Passagens Principais
- **João 4:7-9**: O pedido de água
- **João 4:10-15**: A água viva
- **João 4:16-19**: A revelação pessoal
- **João 4:20-24**: A verdadeira adoração
- **João 4:25-26**: A revelação do Messias
- **João 4:28-30**: O testemunho
- **João 4:39-42**: A fé dos samaritanos

## 🎯 Objetivo Educacional

Este e-book foi criado para:
- Tornar a leitura bíblica mais envolvente e visual
- Ajudar na compreensão da narrativa através de elementos gráficos
- Facilitar o estudo individual ou em grupo
- Demonstrar o amor e inclusividade de Jesus
- Mostrar como Jesus quebrou barreiras sociais e culturais

## 💡 Dicas de Uso

- **Para estudo pessoal**: Leia com calma, refletindo em cada diálogo
- **Para grupos**: Use como base para discussões sobre inclusão e evangelismo
- **Para crianças**: O formato visual torna a história mais acessível
- **Para apresentações**: Use o modo tela cheia para compartilhar em grupos
